# OGK Threat Model (STRIDE Analysis)

## 1. Architecture & Trust Boundaries
1. **Boundary A — Parent/Child Browser ↔ OGK-Server (TLS 1.2+):** Untrusted network; protected by HTTPS, Argon2id + lockout, `HttpOnly`/`Secure`/`SameSite=Lax` sessions, CSRF tokens, IP rate limiting, and RBAC/Anti-IDOR.
2. **Boundary B — OGK-Agent Service ↔ OGK-Server (TLS 1.2+ + Certificate Pinning):** Untrusted network; protected by SHA-256 leaf certificate pinning, short-lived Bearer `access_token` (15 min) + revocable `refresh_token`, and per-device `HMAC-SHA256` policy signatures.
3. **Boundary C — Windows User Session (Child) ↔ LocalSystem Service:** Local untrusted standard user; protected by Windows ACLs on `C:\ProgramData\OGK-Agent` (`SYSTEM` & `Administrators` write-only), authenticated `127.0.0.1` IPC (`X-OGK-IPC-Token`), `time.monotonic()` anti-tamper clock, SHA-256 binary hashing, and mandatory Anti-Abuse Tray watchdog.

## 2. STRIDE Threat Table (10 Threats)

| ID | STRIDE Category | Threat Scenario | Impact | Implemented Mitigation | Verification |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **T1** | **Spoofing** | Attacker intercepts Agent ↔ Server traffic with a rogue CA or MITM proxy to push fake policies or steal device tokens. | High | TLS 1.2+ with strict **SHA-256 Certificate Pinning** (`verify_server_cert_pin()` in `agent/src/service/net_client.py`); Agent refuses any mismatched certificate. | Unit/runtime pin check (`CertificatePinningError`). |
| **T2** | **Spoofing** | Brute-force or credential-stuffing attack against Parent login (`/auth/login`). | High | `Argon2id` password hashing (min 10 chars), **15-minute account lockout after 5 failed attempts** (`423 Locked`), and sliding-window **IP rate limiting** (`429`). | `test_auth_login_lockout_after_5_failed_attempts_and_session_logout`, `test_ip_rate_limiter_enforces_window_limit`. |
| **T3** | **Tampering** | Child rolls back Windows system clock (e.g., by 3 hours) to reset daily screen-time quota or bypass the 7×48 schedule. | High | Elapsed usage tracked via `time.monotonic()` anchored to `server_time` on every 60s heartbeat (`ScreenTimeEngine`). Clock rollback never resets quota and logs a `clock_tamper_detected` event. | `test_screentime_clock_rollback_3h_does_not_restore_quota`, `test_heartbeat_clock_tamper_detection_and_realtime_websocket_commands`. |
| **T4** | **Tampering** | MITM or local attacker modifies a cached or in-transit policy JSON to grant unlimited screen time or remove blocked domains. | High | Every policy is canonically serialized and signed with **HMAC-SHA256** using a per-device secret. Agent verifies `verify_policy_hmac()` before caching/applying and rejects tampered policies (`PolicyTamperError`). | `test_hmac_policy_signature_valid_and_tamper_rejected`, `test_policy_hmac_signed_delivery_and_audit_log_visibility`. |
| **T5** | **Tampering** | Child renames a blocked executable (e.g. `notepad.exe` → `game.exe`) to evade process-name filtering. | Medium | `AppController` computes and caches the **SHA-256 digest** of each running executable binary and matches both process name AND SHA-256 hash. | `test_app_controller_detects_renamed_executable_by_sha256`. |
| **T6** | **Tampering** | Standard Windows user edits or deletes `C:\ProgramData\OGK-Agent\ogk_agent.db` to erase usage counters or policies. | High | `install_agent.ps1` strips inherited ACLs (`icacls /inheritance:r`) and grants write permissions **only** to `SYSTEM` and `Administrators`. Secrets inside SQLite are encrypted with Windows DPAPI (`CRYPTPROTECT_LOCAL_MACHINE`). | `install_agent.ps1` ACL hardening + `test_agent_dpapi_fallback_protect_unprotect`. |
| **T7** | **Repudiation** | Parent silently changes rules or wipes data without the child knowing, violating the companion philosophy; or disputes who made a change. | Medium | Immutable `audit_logs` table records `actor_email`, `actor_role`, `timestamp`, `source_ip`, `old_value`, and `new_value` for every mutation, exposed read-only to both parents and the child (`/audit`, `/child`, Tray UI). | `test_policy_hmac_signed_delivery_and_audit_log_visibility`. |
| **T8** | **Information Disclosure** | Cross-family **IDOR** (Parent B requests `/policy/{child_id}` or `/reports/summary/{child_id}` belonging to Parent A), or leakage of full URLs / PII from DB backup. | High | Strict ownership filtering at the SQLAlchemy query layer (`get_owned_child_or_404`, `get_owned_device_or_404`); child names & device HMAC secrets encrypted with **AES-256-GCM**; `subject` stripped to SLD/app name only. | `test_rbac_anti_idor_and_child_transparency_dashboard`, `test_aes_gcm_encrypt_decrypt_roundtrip`, `test_second_level_domain_strips_full_urls`. |
| **T9** | **Denial of Service** | Flood of API requests or duplicate offline event replays inflating screen-time metrics or exhausting Server resources. | Medium | Global & auth-specific IP rate-limiting middleware (`429`); unique `idempotency_key` constraint on `events` prevents duplicate counting on offline batch sync; automated 90-day retention purge bounds DB growth. | `test_offline_event_batch_sync_idempotency_and_url_sanitization`, `test_data_retention_90_days_and_delete_all_child_data_wipe`. |
| **T10** | **Elevation of Privilege** | Malicious website triggers **CSRF** to unlock a device or alter policy via Parent's session cookie; OR an abuser attempts to run OGK-Agent in hidden **stealth mode** by killing/suppressing the Tray UI. | High | State-changing web endpoints enforce `SameSite=Lax` + mandatory `X-CSRF-Token` validation against server-side `WebSession`; `child-view` role blocked from mutating endpoints (`403`). **Anti-Abuse Watchdog**: if Tray UI cannot display its icon or stops sending authenticated heartbeats, the Service self-terminates and logs the event. | `test_csrf_protection_blocks_state_changing_without_token`, `test_rbac_anti_idor_and_child_transparency_dashboard`, `AgentCore._log_and_self_terminate`. |
